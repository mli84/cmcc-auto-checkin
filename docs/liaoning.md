# 辽宁移动活动

本文件归档辽宁移动专属活动的玩法说明与脚本用法。脚本与凭证均在
`liaoning/` 目录，**仅限辽宁移动实名号码**，其他号码运行会被活动地域
校验拦截（脚本会友好提示）。

## 充值先领券

| 项 | 内容 |
|----|------|
| 活动页 | `wx.10086.cn/qwhdhub/goldeneggs/1025093012` |
| 周期 | 2025-09-30 ~ 2026-12-31 |
| 玩法 | 每日进活动页抽奖 1 次，随机中充值话费券——以 9~9.95 折充值折扣券为主，另有满减/加赠/小额兑换券（含当日券、次日券、次月券等形态）；做任务加抽奖机会 |
| 限制 | 仅辽宁移动实名个人客户（行业卡/物联网卡/CPE/副号不支持） |
| 到账 | 中奖即存入 App「我的卡券」：当日券到账即可用、次日券次日起可用（有效期 5 天），非当月券生效月 1~5 日可用，逾期不补 |

### 配置与脚本用法

1. 凭证配置文件为根目录 `config3.json`（含辽宁号码的 phone / province_code /
   city_code / jwt / app_token 字段，抓包获取方式见主 README「获取凭证」；
   已被 `.gitignore` 覆盖，不会进入仓库）；

2. 运行（**命令需在项目根目录执行**；默认读根目录 `config.json`，非辽宁号码
   会提示地域不符，辽宁号码请用 `--config config3.json` 指定）：

   ```bash
   python3 liaoning/liaoning.py --config config3.json
   python3 liaoning/liaoning.py --config config3.json --dry-run
   ```

每次运行结果通过 Bark 推送（`config3.json` 里配置 `bark_url` 即可）。

### 自动化内容

- **每日抽奖**：自动完成，中奖结果如实推送；
- **任务加成**：次数用完时服务端会下发当前可做任务（DO_TASK 协议），
  浏览/hvb 类自动完成后重抽；邀请类（需真实好友）跳过；
- **任务缺口**：「参与东北"超"级酷」（5元话费券天天领，完成后 +1 抽奖
  机会）的 startBrowse/finish 报文细节待抓包补充，暂不自动做；
- **不做**：邀请好友类（需真实受邀者）。
